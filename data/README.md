# Data

**Language:** English · [中文](README_cn.md)

Real-data benchmarks use two external sources:

- Matbench `expt_gap`: 4,603 experimental band gaps, MIT licence, included in
  `data/external/matbench_expt_gap.json.gz`;
- EES Catalysis TiO2 HER table: 552 complete records, downloaded locally by
  `python scripts/fetch_data.py` and not redistributed.

See `data/README_en.md` for the full schema and `docs/DATA_en.md` for
processing, licences and limitations.

The synthetic scenario generated by `python -m photocat demo` is separate and is
not used as evidence.
